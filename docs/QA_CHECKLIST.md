# 验收清单

每次新增歌曲、替换音频或修改时间轴后至少检查以下项目。

## 数据一致性

- SRT、annotation、中文翻译和逐字时间的句数一致。
- 四份数据中的日文逐句一致，忽略分词空格后仍完全相同。
- ruby 展开的日文序列与逐字 `chars[].char` 一致。
- 每个发音字符都有非空罗马音；标点符号允许空读音。
- 除合理拗音外，没有一条 reading 横跨多个显示字符。

## 时间

- 所有句子和字符时间均为非负数。
- 每个字符满足 `句首 ≤ start ≤ end ≤ 句尾`。
- 字符时间不倒序。
- 前奏、间奏、停顿和尾奏没有被歌词覆盖。
- 重复副歌分别试听。
- 最后一字完整覆盖拖音，下一句没有提前出现。

## 读音和排版

- 助词 `は/を/へ` 使用实际发音。
- 特殊汉字读音已对照实际演唱。
- 罗马音位于对应日文字符正上方。
- 最长句在目标分辨率下不越界。
- 两行歌词不与中文翻译重叠。
- 换句滚动时没有重影或裁切。

## 音频

- 播放音频与制作字幕时的版本一致。
- 播放音频为双声道高质量文件。
- 16 kHz 单声道分析 WAV 没有被误设为播放音频。
- 从开头、首次副歌、间奏后和结尾抽查同步。

## 发布前

- `py scripts/validate_song.py` 通过。
- `py main.py --list` 只显示计划公开的歌曲。
- `git status` 中没有音频、视频、缓存、临时截图或模型文件。
- 全仓库搜索不到私人路径、其他未公开歌曲名称或下载凭据。
